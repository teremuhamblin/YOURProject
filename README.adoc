== Mission
YOURProject est un template universel multi‑langages conçu pour fournir une base stable, professionnelle et sécurisée pour n’importe quel projet GitHub.

== Capacités
- Compatible Python, Node.js, Java, Go, Rust, .NET
- CI/CD universel
- Documentation AsciiDoc complète
- Gouvernance GitHub intégrée
- Sécurité Zero‑Trust v1.6
